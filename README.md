# tech-demos

Sticky monorepo for weekday X-bookmark tech demos.

Each approved pick lives under `apps/<slug>/` as a self-contained Bun app (`bun install && bun run dev`). Do not create a new repository per demo.

Pull requests must include **both** at least one screenshot **and** at least one video of the running app.

See `AGENTS.md` for how Cursor cloud agents should add demos.
